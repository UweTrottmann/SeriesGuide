--- layout: help title: "The release time of a show or episode is wrong" ---

ℹ️ Edit the release time using the clock button in the overview or details screen of each show.

ℹ️ For shows and episodes, only the release time and day of the original release are displayed. If you want to know the release time in your region, please look for a suitable offering for your region, for example a TV guide.

How SeriesGuide determines the release time and day:

If the release country is known, SeriesGuide assumes the release time is in a time zone of this country (for example Eastern Time for US shows, UK Time for British shows, Central European Time for German shows). Then it is converted to your device's time zone.

If the release country is not known, SeriesGuide will assume the country to be the United States and default to the Eastern ("America/New_York") time zone.

You can view the country used to determine release times in the show details.

If your device is set to the US Mountain, Arizona or Pacific time zone, SeriesGuide will automatically adjust the release time (for example, one hour earlier in Central Time).

The release time may differ depending on the date, if the release country is using daylight saving time.

If the displayed country is not correct, it can be changed at the data source.

If the country is correct, but you believe the release time is incorrectly converted in SeriesGuide, please report it.
